# aichat

Очень простое веб-приложение на Gleam: задаёшь вопрос в форме, правишь при желании
JSON запроса, отправляешь его в AI API (`https://api.veai.ru/openai/api/v1/chat/completions`),
смотришь ответ, а пара запрос/ответ сохраняется в SQLite.

Возможности:

- JSON запроса можно редактировать прямо в форме — отправляется именно то, что в поле.
- Кнопка «Форматировать» выравнивает JSON, кнопка «Собрать заново» возвращает
  шаблон с текущим вопросом. Валидность проверяется при вводе и на сервере.
- Блоки с JSON сворачиваются (`<details>`), ответ в них выводится с отступами.
- Текст ответа модели показывается в отдельном поле, без JSON вокруг.

## Запуск

```sh
export OPENAI_API_KEY=...      # ключ провайдера
gleam run                      # по умолчанию http://localhost:8000
PORT=3000 gleam run            # другой порт
```

Тесты:

```sh
gleam test
```

## Как устроено

| Файл | Назначение |
| --- | --- |
| `src/aichat.gleam` | точка входа: миграция БД, конфиг, запуск mist |
| `src/aichat/ai.gleam` | сборка JSON запроса, HTTP-вызов API, разбор ответа |
| `src/aichat/db.gleam` | SQLite: таблица `exchanges`, вставка и чтение |
| `src/aichat/web.gleam` | маршруты и HTML |

Маршруты:

- `GET /` — форма: вопрос + редактируемый JSON запроса.
- `POST /ask` — проверяет JSON, отправляет его в API, сохраняет в базу, редиректит на результат.
- `GET /exchanges/:id` — ответ отдельным полем, JSON запроса и ответа в сворачиваемых блоках.

Модель и вопрос для истории берутся из отправленного JSON, поэтому ручные правки
сохраняются корректно.

База создаётся автоматически в файле `aichat.sqlite` рядом с проектом.
